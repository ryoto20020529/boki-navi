# 05 講師への業務委託条件のお知らせ

院生講師に依頼するとき、**授業の前に**送る。講師から「承諾します」の返信をもらう。
フリーランスに業務を委託するときは、業務内容・報酬額・支払期日などを書面またはメール等で明示する必要がある（フリーランス保護新法）。

**件名:** 【簿記合格ナビ】業務委託の条件のお知らせ（予約番号【0001】）

```
【講師名】様

簿記合格ナビの有村です。
下記の条件で、個別指導の業務をお願いしたく、ご連絡します。

■ 委託者
・簿記合格ナビ　有村稜斗（個人事業主）

■ 受託者
・【講師名】様

■ 業務の内容
・【日商簿記2級】の個別指導（1コマ60分）
・授業後、受講者からのメールでの質問への回答（【次回授業まで・1回まで】）
・授業後の簡単な報告（進んだ範囲・次回の予定）を運営者にメールで送ること

■ 実施日時・方法
・【2026年11月20日（金）20:00〜21:00】
・【オンライン（Google Meet）】／【対面（場所：○○）】

■ 報酬
・1コマ【　　　】円（【税込】）
・【対面の場合の交通費：実費を支給／報酬に含む】
・支払期日：【授業を行った月の翌月末日】まで（遅くとも授業日から60日以内）
・支払方法：銀行振込（振込手数料は運営者が負担）

■ 確認事項
・日商簿記の指導は、受講する級と同じ級以上の資格をお持ちの方にお願いしています。
　初回のご依頼時に、合格証書の写しと、早稲田大学大学院会計研究科の在籍が
　わかるものをご提示ください。
・受講者の氏名・連絡先・学習状況などの個人情報は、この業務以外に使わず、
　第三者に伝えないでください。業務の終了後は削除してください。
・運営者を通さずに、受講者と直接契約することはご遠慮ください。
・受講者の都合によるキャンセルの場合の報酬：【前日まで：なし／当日：報酬の50%】
・ご自身の都合で実施できなくなった場合は、わかった時点ですぐにご連絡ください。
・この業務は雇用ではなく業務委託です。報酬に関する確定申告は、ご自身でお願いします。

上記の条件でお引き受けいただける場合は、
このメールに「承諾します」とご返信ください。

簿記合格ナビ　有村稜斗
wasecpa.academy@gmail.com
```

## メモ（運営者向け）
- 報酬額は運営者が決める。【 】のまま送らない。
- 支払期日は、授業日から60日以内で、できるだけ早い日にする。
- 資格・在籍の確認をした日を、管理表に記録する（証書の写しそのものは、不要になったら削除する）。
- 源泉徴収が必要かどうかは、状況によって変わるので、税務署に確認する。
