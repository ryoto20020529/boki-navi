# 運営書類（簿記合格ナビ）

依頼を受けてから授業・入金・講師への支払いまでに使う書類。`docs/` は公開サイトには出ない。

| ファイル | 使う場面 |
|---|---|
| `01-first-reply.md` | 相談フォームが届いたとき（24時間以内に返信） |
| `02-enrollment-confirmation.md` | 講師・日時が決まったとき（**これが契約の記録になる**） |
| `03-invoice.md` | 授業料を請求するとき（口座はここで初めて伝える） |
| `04-payment-received.md` | 入金を確認したとき（領収の記録） |
| `05-tutor-terms.md` | 院生講師に依頼するとき（業務委託の条件の明示） |
| `ledger-template.csv` | 売上・入金・講師報酬の管理表（Googleスプレッドシートに読み込む） |
| `checklist.md` | 1件の依頼ごとのチェックリスト |

## 使い方
- `【 】` の部分を書き換えて送る。料金は `AGENTS.md` の料金表と同じ金額を使う。
- 送ったメールと、受講者からの「同意します」の返信は消さずに保存する（トラブル時の証拠になる）。
- 予約番号は `0001` から連番にし、管理表・請求・振込名義で同じ番号を使う。

## 注意
- ここにある文面は一般的な整理に基づくひな形で、弁護士・税理士の確認を経たものではない。
- 銀行口座の番号を、このリポジトリやサイトに書かない（メールでのみ伝える）。
- 受講者・講師の個人情報を、このリポジトリに保存しない（管理表は自分のGoogleドライブ等で管理する）。
