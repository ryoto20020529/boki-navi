# 依頼1件ごとのチェックリスト

## 相談が届いたら
- [ ] 24時間以内に `01` を返信した
- [ ] コース・級、目標の試験日、現在のレベル、希望日時、受講形式を確認した
- [ ] 18歳未満かどうかを確認した（該当する場合は保護者の同意を得る）

## 講師を決める
- [ ] 担当講師を決めた（自分／院生）
- [ ] 講師が、受講する級と同じ級以上の日商簿記を持っていることを合格証書で確認した（1級は1級保持者）
- [ ] 講師が早稲田大学大学院会計研究科に在籍していることを確認した
- [ ] 院生に依頼する場合：`05` を送り、「承諾します」の返信をもらった
- [ ] 講師が見つからない場合：その旨を受講者に連絡した

## 契約と入金
- [ ] `02` を送り、「同意します」の返信をもらった（返信メールを保存）
- [ ] 請求は1か月分だけになっている（複数月分をまとめて受け取らない）
- [ ] 支払期限が「翌月分は前月の末日（開始月は最初の授業の前日）」になっている
- [ ] `03` を送った（口座はメールでのみ伝えた）
- [ ] 入金を確認し、`04` を送った
- [ ] 管理表に、請求日・入金日・金額を記録した

## 授業
- [ ] オンライン：授業のURLを伝えた／対面：場所と時間を伝えた
- [ ] 授業後、講師から報告を受け取った
- [ ] 次回の日程を決めた（次回分の `02`〜`04` を繰り返す）

## 毎月の決まった作業（継続の受講者）
- [ ] 前月20日まで：翌月の回数・日程と、休会・退会の有無を受講者と確認した
- [ ] 前月25日頃まで：翌月分の `02`（内容の確認）と `03`（請求）を送った
- [ ] 前月の末日まで：入金を確認し、その日のうちに `04` を送った
- [ ] 欠席・振替があった月：振替の期限（欠席した授業の翌月末日）を管理表に書いた
- [ ] 振替できなかった分：翌月分への充当か返金かを受講者に確認し、14日以内に処理した

## 授業のあと
- [ ] 講師に報酬を支払期日までに支払い、管理表に記録した
- [ ] キャンセル・返金があった場合：規約どおりに処理し、記録した
- [ ] 受講者の声を掲載したい場合：本人の了承を文面でもらった

## 事業の準備（最初に1回）
- [ ] 開業届を出した
- [ ] 青色申告承認申請書を出した（開業から2か月以内）
- [ ] 入金用の口座を決めた（できれば事業専用）
- [ ] 会計ソフトまたは帳簿を用意した
- [ ] 住所・電話番号の開示を求められたときに、すぐ答えられるようにした（特商法の表記で「請求があれば開示」としているため）
