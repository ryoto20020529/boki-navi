# 支払い・規約の見直しレポート（2026-11-14）

運営者の指示：①支払いは「月初に前払い」にする ②「前日払い」などの細かい期日はトップページに載せず、規約に載せる ③世の中の家庭教師・個別指導の規約を調べて反映する。

※ 法律面は一般的な整理で、弁護士の確認を経たものではない。他社の規約は、検索で確認できた公開情報にもとづく（各社のサイトを直接開いて全文を読むことは、作業環境の通信制限でできなかった）。

## 1. 他社の支払い・規約の傾向（調査結果）

| 項目 | 見られた型 | 例 |
|---|---|---|
| 支払いの時期 | **前払い**（翌月分・当月分を月初や前月末に） | 翌月分を月初に預かり、未消化分は翌月に精算する型／次月分を当月27日に口座振替する型 |
| | **当月払い** | 当月分を当月6日まで・27日までに振込や口座振替（「前払いの必要なし」と明記） |
| | **後払い**（月末締め・翌月払い） | 個人契約に多い。実施した回数分を月末または翌月に支払う |
| 契約の単位 | 月単位（月謝制）が多い | 「月単位での契約の前払い制」 |
| 欠席・振替 | 前日までの連絡で振替。当日は50〜100%のキャンセル料 | 個人契約・個別指導で一般的 |
| 振替の期限 | 「欠席から1か月以内」などの期限を置く | ひな形・解説で推奨されている |
| 休会・退会 | 「前月5日まで」「前月20日まで」に連絡、などの締め日を置く | 塾の事務規定 |
| 返金 | 未受講分を返す会社と、「支払い済みは返金しない」とする会社がある | 後者は無効になるおそれが指摘されている |

**わかったこと**
- 前払い・当月払い・後払いのどれも実例があり、「月初に前払い」は一般的な型の1つ。
- 月謝制（1か月ごとの契約）は、原則として特定商取引法の「特定継続的役務提供」に当たらないとされる。ただし、教材の販売や長期の拘束で**実態として2か月を超えて縛る**と、該当するおそれがある。
- 「支払い済みの授業料は一切返金しない」という条項は、消費者契約法で無効になるおそれが高いと解説されている。

## 2. 決めたルール

| 項目 | 内容 |
|---|---|
| 契約の単位 | 1か月（暦月）ごと。自動更新なし。前月25日頃までに翌月の回数と日程を確認する |
| 支払い方法 | 銀行振込（手数料は受講生負担） |
| 支払いの時期 | その月の回数分を月初に前払い。**毎月5日まで**（最初の授業が5日以前なら、その前日まで） |
| 請求 | 前月の末日までにメールで請求する |
| 途中開始・1回だけの受講 | 最初の授業の前日まで |
| 前払いの範囲 | 1か月分まで。複数月分は受け取らない |
| 欠席・キャンセル | 前日23:59まで：無料で振替／当日・開始2時間前まで：50%／それ以降・無断欠席：100% |
| 振替の期限 | 欠席した授業の翌月末日まで。合わなければ、翌月分に充当または返金 |
| 講師の都合 | 振替または全額返金 |
| 遅刻・通信の不具合 | 受講生の遅刻は終了時刻どおり。講師の遅刻・講師側の不具合は延長または振替 |
| 休会・退会 | いつでも可。解約金なし。未受講分は全額返金（14日以内） |
| 料金の改定 | 1か月前までに知らせる。支払い済みの月は変えない |

**「毎月5日」は仮の日付。** 指示は「月初に前払い」だったので、月初で区切りのよい日として5日を置いた。変えたい場合は、規約・特商法の表記・ひな形・自動チェック（`tools/check.py` の「毎月5日」）を同時に直す。

## 3. どこを、なぜ直したか

| 場所 | 修正 | 理由 |
|---|---|---|
| トップ：FAQ「支払い方法は？」 | 「授業前日までに振込」を削除し、「月初に前払い。詳細は利用規約」に変更（構造化データも同じ文に） | 細かい期日はトップに載せない、という指示。トップと規約の二重管理をなくし、食い違いを防ぐ |
| トップ：料金欄の注記 | 「事前銀行振込制」→「月初の前払い（銀行振込）。詳しくは利用規約」 | 同上 |
| トップ：FAQ「1回だけの受講」 | 「まとめ予約（5万円以下・2か月分まで）」→「月ごとに回数を決めて受講」 | まとめ払いをやめ、月ごとの前払いにしたため |
| トップ：「講師の決め方」 | 「事前振込制」→「お支払いは講師と日程が決まってから」 | 用語を新しい支払い方に合わせた |
| 利用規約 第3条 | 契約が成立する時点（同意のメールの返信）、1か月ごとの契約、自動更新なしを明記 | いつ・何について契約したのかを明確にする。月謝制を「長期の拘束」と受け取られないようにする |
| 利用規約 第4条 | 月初の前払い、支払期日、請求の時期、途中開始、前払いは1か月分まで、未入金時の扱い、料金の改定を規定 | 支払いの決まりを1か所にまとめる。前払いを1か月分に限り、特定継続的役務提供に当たらない形を保つ |
| 利用規約 第5条 | 振替とその期限、当日キャンセルの残り50%の扱い、遅刻、通信の不具合、休会・退会と返金の期限を追加 | 前払いにすると「払ったのに受けられなかった分」が必ず生じる。その扱いを先に決めておかないとトラブルになる |
| 特商法の表記 | 支払方法・支払時期・キャンセル・中途解約を、規約と同じ内容に更新 | 特定商取引法で、支払いの時期と方法、返金の条件の表示が義務づけられている。規約と一致させる |
| 運営書類（`docs/operations/`） | 確認メール・請求メールを月単位に変更。毎月の作業のチェックリストと、管理表の列（対象月・支払期限・振替待ち・充当/返金）を追加 | 実際の運用を規約どおりに行えるようにする |
| 自動チェック | 規約・特商法に必須の文言があるか、トップ・コース・コラムに支払期日が書かれていないかを検査 | 今後の修正で、食い違いや書き戻しが起きないようにする |
| `AGENTS.md` | 支払い・契約のルールと、サイトと規約の書き分けを追記 | ほかの作業者（AIを含む）が同じ決まりを守れるようにする |

## 4. 今後、気をつける点

1. **前払いで受け取ったら、すぐ知らせる。** 代金を先に受け取る通信販売では、受け取ったことを遅滞なく通知する義務がある（特定商取引法）。入金を確認したら、その日のうちに `04` のメールを送る。
2. **請求を期日どおりに送る。** 規約に「前月の末日までに請求」と書いた。送り忘れると、受講生は5日までに払えない。
3. **複数月分を受け取らない。** 「3か月分まとめて払いたい」と言われても断る。2か月を超え、合計5万円を超える前払いは、特定継続的役務提供の規制（書面の交付、クーリング・オフ、中途解約のルール）の対象になるおそれがある。
4. **教材を売らない。** 教材の販売は、月謝制でも長期の拘束とみなされる原因になる。受講生が自分で用意する形を続ける。
5. **返金を渋らない。** 未受講分は、申し出から14日以内に返す。「返金しない」という運用は、条項が無効になるおそれがあり、苦情のもとにもなる。
6. **振替の期限を管理する。** 欠席した授業ごとに、振替の期限（翌月末日）を管理表に書く。期限が来たら、充当か返金かを受講生に確認する。
7. **講師への支払いと混同しない。** 受講生からの前払いは、授業をするまでは「預かっているお金」に近い。講師への報酬は授業のあとに支払うので、返金に備えて使い込まない。
8. **帳簿の付け方。** 前払いで受け取った授業料は、授業をした月の売上にするのが原則（年をまたぐ12月・1月は特に注意）。処理は税務署または会計ソフトの案内で確認する。
9. **規約を変えたら、記録を残す。** 規約の最終更新日を直し、受講中の人にはメールで知らせる。変更前の規約も保存しておく。
10. **サイトと規約を必ずそろえる。** 支払い・キャンセル・返金の決まりを変えるときは、規約・特商法の表記・ひな形・トップのFAQを同時に直し、`python3 tools/check.py` を通す。

## 5. 運営者に決めてほしい点
- 支払期日は「毎月5日」でよいか（1日・3日・10日などに変えられる）。
- 振替の期限は「翌月末日まで」でよいか。
- 当日キャンセル（開始2時間前まで）の残り50%を「振替または返金」とした扱いでよいか。
- すでに受講が始まっている人がいる場合、新しい決まりをいつの月から適用するか（知らせてから適用する）。
