## 2. 旧サイト監査で見つかった問題と対応
| 問題 | 重要度 | 対応 |
|---|---|---|
| `og:image`（ogp.png）が存在せず404 → SNSシェア時に画像なし | Critical | 1200×630のOGP画像を作成 |
| 1ページに4事業を詰め込み、科目別キーワードで上位表示しにくい | High | 科目別LPを4本新設（/boki /toukei /actuary /acaschool） |
| 料金表の初期表示が「対面」で、ヒーローの「2,800円〜」と食い違う | High（UX） | 初期表示をオンラインに統一し、両方の列を常に表示 |
| noindexの法務ページがsitemapに入っていた（シグナル矛盾） | Medium | sitemapから除外 |
| Webフォント（Noto Sans JP）読み込みでLCPが悪化 | Medium | システムフォントに変更 |
| FAQの価格が本文と不一致（アカスク6,000円と7,000円の混在） | Medium | 構造化データと本文を同一テキストに統一 |
| faviconなし・meta keywords（評価対象外） | Low | favicon.svg / apple-touch-icon を追加、keywordsは削除 |
| 特商法表記に簿記以外の料金がない | 法務 | 全6コースの料金を追記 |

## 3. 実装したSEO施策
- **ページ設計**: トップ＝ビッグワード（簿記 個別指導／オンライン家庭教師）、科目別LP＝ロングテール（統計検定 個別指導、アクチュアリー 数学 家庭教師、早稲田 アカスク 受験対策 など）
- **構造化データ**: WebSite / EducationalOrganization＋OfferCatalog（UnitPriceSpecification）/ FAQPage / BreadcrumbList / Course＋CourseInstance（Online・Onsite）
- **オンページ**: 各ページでtitleとdescriptionを固有化し、H1は1つ、canonical・OGP・Twitter Cardを設定、パンくずを表示
- **内部リンク**: トップ⇄科目別LP、科目別LP同士の相互リンク、フッターの全コースリンク
- **外部の権威リンク**: 各試験の公式サイト（商工会議所・統計検定・日本アクチュアリー会・早稲田大学）
- **技術**: cleanUrls、静的アセットのキャッシュヘッダー、セキュリティヘッダー、`.vercelignore` でsrc/toolsを非公開化
- **CVR/UX**（参考LPの型）: 悩み提起→解決→理由3つ→料金表→月額シミュレーター→他の学び方との比較→プラン例→講師→流れ→FAQ→フォーム。スマホでは追従CTAを表示。科目別LPからはフォームのコースを事前選択した状態で遷移

## 4. 運用で必要なこと（社長の判断事項）
- 公開後、Search Consoleにsitemapを再送信し、4本の新URLのインデックス登録をリクエスト
- **実際の受講者の声・合格報告**が集まったら掲載する（現状は架空の体験談を載せず「プラン例」として表記）
- 独自ドメインの取得（vercel.appのままでは信頼性・被リンク面で不利）
- 次の施策案: 「簿記2級 独学 つまずく論点」などの解説記事（コラム）でトピッククラスターを構築

## 5. 編集方法
共通パーツは `src/partials/`、ページ本文は `src/pages/` で編集し、`python3 tools/build.py` を実行するとルート直下のHTMLが生成される。
